## Notes

- Scope: TAS runs only NovAI robots, so the NovAI build applies (`VITE_IS_NOVAI=true` in NovApp's `.env`, read in `vite.config.ts` line 9; it selects `src/components/widget/` for NovAI and `src/components/widget/swr/` otherwise). Rows 1b, 7 and 8 and the swr files in rows 1 and 6 are on the SWR build's path only, not TAS's. They stay documented and are not measured for TAS.
- The ingester writes OpenSearch documents and, in Postgres, only `weld_presets_associations` (`internal/rds/pgx_repository.go` line 70). `weld_run`, `weld_run_end` and `weld_files` in NovApi's Postgres are filled by NovSync through NovApi's sync endpoints, which is why they are empty locally.

- API version: the dashboard pages in scope call the v2 path (`/api/v2`), except the v1 `weld_test_reports` call of `swr/WeldQualityList.tsx` (row 1b). The v2 batch (`weld_test_reports/batch`) takes only run, part, serial and weld IDs, with no `weld_run_id` input, so that page needs a NovApp change (send those IDs) or a NovApi variant before it can use batch.
- v1 routes for the same data exist (`weld_run`, `weld_run/:run_id`, `weld_run_last`, `weld_run_files`); v1 has no `weld_stats` route. NovApp calls v1 `weld_run` and `weld_run_files` from `src/libs/hooks/useWeldRunsMerged.ts` (lines 27 and 36), used by `swr/WeldSessions.tsx` and `swr/WeldQualityList.tsx`. The non-swr `WeldSessions.tsx` calls v2 `weld_run` (`useRobotsWithWeldRuns.ts` line 9, `WeldRunsByRobotAndDate.tsx` 38-42). No page calls `weld_run_last` or `weld_run/:run_id`. The v1 `weld_run` and `weld_run_files` handlers are not yet read or measured.

- `src/components/widget/swr/WeldSessions.tsx` fires no per-run calls itself. The per-run calls start when a row is clicked and `WeldInformation` (suspect 1) mounts.
- The per-run response is written to the store by RTK Query's own `initiate()` dispatch. There is no custom reducer.
- The comparison batch endpoint (variant B): `routes/api/v2/users.js` 1555-1625, via `db/queries.js` 2163-2185. One Postgres query, no S3.
- Spot-checked by the coordinator against the files: the NovApp dispatch sites in suspect 1 and the start of the NovApi handler at 1204. The other line ranges are as reported by the peers.
